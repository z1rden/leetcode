# Самая длинная строка без повторяющихся символов

Дана строка s. Найдите длину самой длинной подстроки без повторяющихся символов.

## Пример 1:
Ввод: s = «abcabcbb»
Вывод: 3
Объяснение: Ответ — «abc», его длина равна 3.

## Пример 2:
Ввод: s = «bbbbb»
Вывод: 1
Объяснение: Ответ — «b», его длина равна 1.

## Пример 3:
Ввод: s = «pwwkew»
Вывод: 3
Объяснение: Ответ — «wke», его длина равна 3.
Обратите внимание, что ответ должен быть подстрокой, «pwke» — это подпоследовательность, а не подстрока.
