# Обратное целое число
Для 32-битного целого числа со знаком x верните xего с перевёрнутыми цифрами. Если перевёртывание x приводит к выходу за пределы 32-битного целого числа со знаком [-231, 231 - 1], верните 0.

Предположим, что среда не позволяет хранить 64-битные целые числа (со знаком или без знака).

## Пример 1:
Ввод: x = 123
Вывод: 321

## Пример 2:
Входные данные: x = -123
Выходные данные: -321

## Пример 3:
Ввод: x = 120
Вывод: 21
