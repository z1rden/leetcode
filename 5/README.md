# Самая длинная палиндромная подстрока
Для заданной строки s верните самую длинную палиндромную подстроку в s.

## Пример 1:
Входные данные: s = «babad»
Выходные данные: «bab»
Пояснение: «aba» также является допустимым ответом.

## Пример 2:
Ввод: s = «cbbd»
Вывод: «bb»
