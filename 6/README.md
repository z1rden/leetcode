# Самая длинная палиндромная подстрока
Строка "PAYPALISHIRING" записывается в виде зигзага в заданном количестве строк следующим образом: (для лучшей читаемости вы можете отобразить этот узор фиксированным шрифтом).
Затем читайте построчно: "PAHNAPLSIIGYIR".
Напишите код, который будет принимать строку и выполнять это преобразование для заданного количества строк: func convert(s string, numRows int) string

## Пример 1:
Ввод: s = «PAYPALISHIRING», numRows = 3
Вывод: «PAHNAPLSIIGYIR»

## Пример 2:
Ввод: s = «PAYPALISHIRING», количество строк = 4
Вывод: «PINALSIGYAHRPI»

## Пример 3:
Входные данные: s = «A», numRows = 1
Вывод: «A»
